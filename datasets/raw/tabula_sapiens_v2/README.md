# Tabula Sapiens v2 Raw Data

This directory is reserved for Tabula Sapiens v2 raw files downloaded from the
CELLxGENE collection:

```text
e5f58829-1a66-40b5-a624-9046778e74f5
```

Use:

```bash
python scripts/datasets/tabula_sapiens_v2/download.py
```

The downloader writes `collection_metadata.json` and H5AD files under `h5ad/`.
Do not hand-edit raw H5AD files.
