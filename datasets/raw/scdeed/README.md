# scDEED Raw Data

Raw and inspected files for the scDEED Zenodo record:

```text
Zenodo record id: 7216361
Source URL: https://zenodo.org/records/7216361
```

Use `scripts/datasets/scdeed/download.py --list-only` to inspect available
Zenodo files before downloading large archives. Downloaded files belong in
`downloads/`; extracted archive contents belong in `extracted/`.

`inspect_manifest.json` is generated by:

```bash
python scripts/datasets/scdeed/inspect.py
```

The scDEED preparation scripts use this raw directory only. Legacy locations
such as `data/Samusik/` are intentionally not scanned or converted.

Recognized Python-preparable datasets currently include Marrow, Velocity,
Samusik, and CART. Alveolar, Across Techniques, and Simulated Data contain
primary Seurat/custom R objects that are not readable through `pyreadr` in the
current environment; those require a separate R/Seurat extraction step before a
processed dataset can be generated.
